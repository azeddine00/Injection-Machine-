Build the APK without a computer-side Android setup:
1. Create a free GitHub account and a new repository.
2. Upload ALL files of this folder (keep the .github folder).
3. Open the Actions tab, run "Build APK" and wait about 5 minutes.
4. Open the finished run, download "injection-simulator-apk", unzip it and install app-debug.apk on the phone (allow installing from unknown sources).
To change the app, edit www/index.html and upload it again.
